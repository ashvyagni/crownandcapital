# 2D Art Bible

## Shape language
Use irregular but intentional borders, rounded cards for actionable information, and angular map regions that remain distinct at small size. Keep icons geometric and recognizable in monochrome.

## Palette roles
Define tokens by role (paper, ink, muted ink, accent, warning, danger, success) rather than scattering raw colors. Verify text and icon contrast in light and dark surfaces.

## Iconography
Icons should be original, simple silhouettes with consistent stroke/weight. Every icon requires a text label or accessible name when its meaning is not obvious.

## Export guidance
Prefer CSS or inline vectors for interface marks. Raster art should have a documented source, dimensions, and optimization note. Do not add an asset to the catalog without recording provenance.

## Boundary
This bible describes the intended 2D language; it does not certify that all listed components are already drawn or shipped.
